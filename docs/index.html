The failure is silent

Three ways a covenant permits nothing.

CovenantGuard only honours an ALLOWED verdict whose excerpt is a verbatim substring of the stored text, capped at 320 characters. That one rule turns ordinary prose into three deployment hazards. None of them produces an error at runtime; they produce weak rules and downgraded verdicts. covctl reports each at the severity the contract actually implies.

01

Unciteable

A clause longer than the excerpt cap can only be cited in part: the contract truncates a citation at 320 characters, so a ruling may miss a condition in the tail.

02

Indistinct

A clause too short to narrow the decision does not constrain the model. It reads like policy and behaves like noise.

03

Permitted nothing

A policy that only forbids cannot tell a compliant payment from a violation. The guard fails closed, forever.

It also rejects active control language at the boundary (ignore previous instructions) and flags covenants that both permit and prohibit, where a collision would be unresolvable.

Checked against the contract

Parity is a fixture, not a promise.

CovenantGuard’s constants, digest formula and excerpt rule are checked in as a fixture with pinned provenance: repository, path, commit and sha256. Every vector is re-derived independently in the test suite, so a bug shared by the generator and the tool still fails.

covctl selftest 
$ covctl selftest
OK: 4 normalization, 6 digest and 9 excerpt
    vectors match the contract
    fixture: covenant/contracts/covenant_guard.py
             @ 0034b5e40a88
    sha256:  e55b9c3f082c17a300506f1645d8a349
             af5c11be70624e10dbf267d12bee2b12
    contract source not present; verified
    against the checked-in fixture

No fixture means exit 1, never a skip with a success code. If the contract source is present and its sha256 differs from the pin, selftest fails. Files are read with newline="", so CRLF survives to the digest, and the text is stripped exactly as the contract stores it.

Byte for byte

The digest is the contract’s digest.

A compiler that prints the wrong hash is worse than no compiler: the published digest would not match the deployment, and nobody would notice until an auditor checked.

covctl digest reproduces covenant_guard._digest("covenant", [text]) exactly. The value below is pinned in the test suite and matches the live deployment’s get_covenant_hash.

Small surface, sharp edges.

Get started

One file. No dependencies.

Run it straight from a clone, or install the covctl command. Python 3.10 and up. Exit codes: 0 success, 1 errors or a failed check.

git clone https://github.com/vincentofweb3/covctl
python3 covctl.py lint examples/covenant.md
